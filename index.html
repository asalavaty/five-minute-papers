5-Minute Papers Uploader

A single-operator publishing tool for one YouTube channel.

What this is

5-Minute Papers Uploader is a small command-line tool that publishes finished video episodes to the 5-Minute Papers channel on YouTube. It is built on YouTube API Services and is operated by one person: the operator of that channel.

It is not a product, it is not distributed, and it has no users other than its operator. There is no sign-up, no hosted service and no account to create.

What the channel publishes

5-Minute Papers explains one recently published life-science paper per episode in five minutes, for researchers and scientifically literate viewers. Each episode carries original explanatory animation built from the paper’s own reported figures, an assessment of what the paper does and does not establish, and the source citation with its DOI shown on screen and in the description.

What the tool does

Scope of operation
  • Uploads a finished video file to the single channel its operator owns.
  • Sets that video’s title, description, tags, category, thumbnail and playlist.
  • Reads the video back afterwards to confirm the upload succeeded and that its privacy status is what was intended.

That is the whole scope. The tool does not read, collect, store, aggregate or display data about any other channel, video, comment or viewer. It does not search YouTube. It performs no analytics and generates no derived metrics.

Authorisation

The tool signs in once, through Google’s standard OAuth 2.0 consent screen, as the owner of the channel it publishes to. It requests two scopes and no others:

  • youtube.upload, to upload a video to the operator’s own channel.
  • youtube.readonly, to read that video back and verify its status.

The resulting credential is stored only on the operator’s own computer, with file permissions restricting it to that user account. It is never transmitted anywhere except to Google, and it can be revoked at any time from Google Account permissions.

Use of YouTube API Services

This tool uses YouTube API Services. By using it, its operator is bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.
