# 5-Minute Papers Uploader

Public information pages for **5-Minute Papers Uploader**, a single-operator command-line tool that publishes finished video episodes to the 5-Minute Papers channel on YouTube using YouTube API Services.

The tool has one user, its own operator. It is not distributed and has no hosted service. These pages exist to provide the homepage, privacy policy and terms of service that YouTube API Services requires an API client to publish.

- `index.html`: what the tool is and what it accesses
- `privacy.html`: privacy policy
- `terms.html`: terms of service
- `architecture.png`: how the publishing pipeline is arranged
