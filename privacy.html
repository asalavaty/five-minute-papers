Privacy Policy

Effective 18 September 2026

Summary

5-Minute Papers Uploader collects no personal data from anyone. It has a single user, its own operator, and it publishes videos to a single YouTube channel that the operator owns. There is no sign-up, no hosted service, no database of users and no analytics.

Who this policy covers

This policy describes 5-Minute Papers Uploader, referred to here as "the tool", a command-line application operated by the operator of the 5-Minute Papers YouTube channel. The tool is not distributed to other people and cannot be used by anyone other than its operator.

Use of YouTube API Services

The tool uses YouTube API Services. In using YouTube API Services, its operator agrees to be bound by the YouTube Terms of Service.

Google’s collection and use of data is described in the Google Privacy Policy. Data that passes between the tool and YouTube is handled by Google under that policy.

What the tool accesses

YouTube data accessed
  • Write access to one channel. Using the youtube.upload scope, the tool uploads a video file to the operator’s own channel and sets that video’s title, description, tags, category, thumbnail and playlist membership.
  • Read access to that video. Using the youtube.readonly scope, the tool reads back the video it just uploaded to confirm the upload succeeded and that its privacy status is correct.

The tool accesses nothing else. Specifically, it does not access, collect, store, aggregate, transmit or display:

  • data about any other YouTube channel, video or playlist;
  • comments, subscriber information, viewer information or audience data;
  • YouTube Analytics data or any metric derived from it;
  • YouTube search results;
  • any personal information about any person other than its operator.

Authorisation and credentials

The tool authorises through Google’s standard OAuth 2.0 consent flow, as the owner of the channel it publishes to. The resulting access and refresh tokens are stored only on the operator’s own computer, in a file restricted to that user account. Tokens are never transmitted to any destination other than Google’s own authentication and API endpoints, and they are never shared with any third party.

No third-party analytics, advertising, tracking or telemetry service is used by the tool or by this website.

Revoking access

Authorisation granted to the tool can be revoked at any time, with immediate effect, from Google’s own account controls at myaccount.google.com/permissions or security.google.com/settings/security/permissions. Revoking access stops the tool from uploading or reading anything.

Data retention and deletion

The tool stores two things locally, on the operator’s computer only:

  • the OAuth credential described above, which is deleted whenever access is revoked or the file is removed;
  • a plain-text log of each upload, holding the video’s own identifier, its title and the timestamp of the upload, retained for operational record-keeping and deletable at any time.

Neither contains personal information about any person other than the operator. Because no data is collected from anyone else, there is nothing for another person to request access to, correct or have deleted. Any question about this can be sent to the contact address below and will be answered.

Children

The tool is not directed at children and collects no data from anyone, including children.

This website

This site is static. It sets no cookies, runs no scripts and embeds no third-party content. It is hosted on GitHub Pages, whose own server logs are governed by GitHub’s privacy statement.

Changes to this policy

If the tool’s use of YouTube API Services changes materially, this policy will be updated and the effective date above revised, and the change will be notified to YouTube in writing before it takes effect, as required by the YouTube API Services Developer Policies.
